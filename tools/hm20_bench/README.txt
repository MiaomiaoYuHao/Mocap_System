hm20 推理延迟实测（独立包）
=====================================
跟你的项目文件无关，随便解压到一个空文件夹里跑，跑完可以整个删掉。

【在哪台机器上跑】
  在你【实际部署动捕软件】的那台机器上（比如那台 4060 笔记本）。
  云端 GPU 的数字毫无参考价值 —— 你的软件不会跑在租来的卡上。

【依赖】
  pip install torch numpy onnxruntime
  有 N 卡想测 CUDA：pip install onnxruntime-gpu

【跑】
  python bench_all.py --points 22

  --points 按你现场典型候选点数改（你说杂点几乎没有，那就是 20 出头）

【它做什么】
  1. 用随机权重构建 4 个规模的模型（6.9M / 13.2M / 22.5M / 30.6M）
     —— 延迟只取决于结构和输入形状，跟训没训过无关
  2. 导出 ONNX，并逐点校验 ONNX 与 PyTorch 数值一致（这一步很关键，
     这个模型已经踩过三个"导出不报错但图是错的"的坑）
  3. 在 CPU 和 CUDA 上各测 300 次，报中位数和 p95
  4. 打一张表，直接告诉你每个规模能上多少 fps

【结果发回去】
  把最后那张表整个发给我，我对着你的帧率目标和管线预算帮你定模型规模。
