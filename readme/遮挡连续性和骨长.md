# 遮挡点：抖动 / 不连续 / 骨长不对

你说的三件里，前两件做完了，第三件（单相机射线）我先说方案。

---

## 先确认你的观察：INT8 确实让预测位置抖，而我之前测漏了

```
① 跟 FP32 的静态差（我之前量的这个）  中位 0.93mm
② 帧间位移                            0.38 -> 1.31mm   放大 3.5x
③ 二阶差分（消掉匀速运动）             0.200 -> 1.941mm  放大 9.7x
```

我量的是**静态偏差**，你看到的是**帧间抖动**。量化误差每帧独立，
所以帧间抖动接近静态偏差的两倍，二阶差分放大近 10 倍。
而 `pos` 头正是用来补遮挡点的 —— 抖的恰好是"预测位置"。

## ① 骨长回正（你的原话：直接补偿到与先前骨长一致）

对的，而且实现过程中查出**两个**问题：

**A. 骨长学习埋在一个可能被关掉的开关里。**
`pmLen_` / `mdLen_` 的学习写在 `continueChainForOccluded()` 内部，
而那个函数开头就 `if (!cfg_.chainContinue) return;` —— 开关一关，
骨长**永远学不到**，依赖它的一切都失效。骨长是标定量，跟"要不要做链式续解"
是两件独立的事。拆成独立的 `learnBoneLengths()`，无条件执行。

**B. 只回正"父可见"的那一级不够。**
实测中 mp 和 dp 常常一起被遮挡，dp 的父也是补的。只认实测父点的话，
第二级得不到约束：mp-dp 在 **16.50~18.61** 之间飘（真值 18.00）。

改成**沿链逐级**：回正过的点可以当下一级的基准。

```
帧    状态    pp-mp    mp-dp   dp帧间位移
59    可见    25.00    18.00      1.31    snap=0
60    遮挡    24.93    17.93      0.24    snap=2   <- 转遮挡那一帧
99    遮挡    24.85    17.54      0.31    snap=2
真值          25.00    18.00
```

**转遮挡那一帧的位移 0.24mm** —— 你说的"位置不连续"没有了。

## ② 时域平滑

只平滑**补出来的**点，实测点一律不碰（平滑实测点只会加延迟）。
可见时滤波器跟着实测值走，**转遮挡那一帧无缝接上**。

alpha 是扫出来的，不是拍的：

| alpha | 抖动(二阶差分) | 跟真值距离 |
|---|---|---|
| 1.00（关闭） | 5.940 | 2.42 |
| **0.60** | **2.801** | **1.72** |
| 0.35 | 1.423 | 1.97 |
| 0.20 | 0.752 | 3.29 |

**0.6 处抖动减半，而且跟真值的距离反而下降** —— 平滑同时压掉了噪声。
再往下抖动继续降但滞后上来。所以默认 0.6（我最初拍的 0.35 偏保守）。

用低通不用外推是有依据的：代码里记着一次教训，开环外推几十帧就漂到 40°+。
低通只滞后不发散。

## ③ 单相机可见的点：你说得对，但这个改动大得多

**你的判断是对的**：一台相机看到一个点，就把它约束在一条射线上 ——
从 3 个未知数降到 1 个。丢掉这个信息是浪费。

融合方式也很直接：拿预测位置往射线上投影（取射线上最近点），
就消掉了 2 个自由度的误差，只剩沿射线方向的深度不确定。

**但它需要把 2D 光斑和相机标定接进关联器。** 现在关联器只收到三角化好的
3D 候选点，看不到"哪些光斑没配上对"。这条链路要打通：

```
检测 -> 2D 光斑 ┬-> 三角化 -> 3D 点 -> 关联器
                └-> 【未配对的光斑 + 标定】-> 关联器   ← 现在没有这条
```

还要处理几个不平凡的问题：未配对光斑怎么归属到某个 marker（它没有标签）、
一个 marker 可能被多台相机各看到一条射线（那就是欠定的三角化，可以直接解）、
以及射线本身的外点。

**代价大概是几百行 + 一套新的失效模式。** 我建议先上前两件、看效果，
再决定要不要做这个 —— 前两件已经把"不连续"和"抖"解决了，
射线融合解决的是另一个问题（遮挡点的绝对精度）。

要做的话我先出方案文档，不直接动手。

**顺序放错了。** 第一版我把这两步插在链式续解之后，但"发散限速"那段在更后面，
它拿**未回正的原始值**去判发散并覆写，把前面做的全冲掉 ——
骨长从 25mm 变成 71mm。正确位置是限速之后、`prevMarkerPos_` 回填之前。

**测试后端写错了。** 我按下标给 `log_assign` 高概率，等于让模型"认领"了
根本没喂进去的标签，遮挡点被标成 observed，测试测不到任何东西 ——
四行输出跟修改前一模一样，差点当成"改了没用"。
