# 怎么看这些数

你问得对 —— 我查了一遍，**这一轮做的东西你原本看不到**：

```
chainContinued     面板 ✓
dorsumInliers      面板 ✓
dorsumSelfAmbMm    面板 ✓
autoBundleRmseMm   面板 ✓
dorsumRepaired     面板 ✗   ← 贴点重捕，只存在关联器内部
thumbIpPredRad     面板 ✗   ← 拇指跟随
thumbIpDriftRad    面板 ✗   ← 同上
```

也就是说贴点重捕和拇指跟随做完了，但你没有任何办法确认它们有没有工作。
**已经接上了**：关联器 → diag 快照 → 面板 → 录制块，四层都通。

---

## 一、面板上直接看（推荐，实时）

监控面板的诊断文字里现在有这几行。**没有触发条件的行不会显示**，
所以看不到某一行本身就是信息。

### 手背刚体（每帧都有）

```
手背刚体：内点4/5  残差0.83mm  裕度9.1mm  [连续性仲裁]   自歧义4.30mm
手背刚体：未解出 —— 歧义拒解(本帧不给腕部位姿)
```

| 看什么 | 正常 | 不正常说明 |
|---|---|---|
| 内点 | 5/5 或 4/5 | 长期 4/5 且不恢复 = 有球掉了没重捕上 |
| 残差 | < 1.5mm | 大 = 贴球移位或粘连 |
| 自歧义 | > 6mm 好，< 3mm 病态 | **< 3mm 会直接把"重贴布局"那句话打出来** |
| [连续性仲裁] | 偶尔出现 | 一直出现 = 单帧裕度长期不够 |

### 遮挡处理（**这是本轮新增的，最该看**）

```
遮挡处理：拇指尖遮挡 跟随IP 47°(已跟 -13.2°)   链式续解×3
遮挡处理：拇指尖遮挡 但跟随未生效(chainContinue 关?)
遮挡处理：★手背模板已修复 槽位0 移动14.4mm
```

| 看什么 | 说明 |
|---|---|
| `跟随IP xx°` | 当帧给拇指的 IP 角。遮挡期它应该**跟着 MCP 动**，不是钉死 |
| `(已跟 xx°)` | 相对遮挡入口累计跟了多少。**恒为 0.0 = 跟随没生效** |
| `但跟随未生效` | 直接告诉你 `chainContinue` 没打开 |
| `链式续解×N` | N 是本帧顺着可见近端解出来的遮挡点数。**恒为 0 = 总闸关着** |
| `★手背模板已修复` | 球掉了重贴回去被认回来了。带 ★ 是因为它改了模板，要留意 |

### 网络段常数（只在跑过标定后出现）

```
网络段常数：C离散3.2°  拇指修正 78°/81°/75°  ← 与模型量到的 73° 对上了
```

## 二、录完之后看（推荐，能做统计）

面板只能看当前帧。要看**分布**和**时间线**就得用录制文件：

```bash
python tools/hm20_diag/pcrec_report.py recordings/xxx/capture.pcrec
```

七节报告，每节对应一个已知失效模式，格式是「量到的数 → 判据 → 结论 → 该怎么办」。
上面所有的数它都会自己算、自己判，不用你记阈值。

比如它会直接告诉你：

```
❌ 【IK 全程 0% 生效】—— 上面那些拇指参数【一个都没被用上】。
   ikUsable() 要求 bundleRmseMm < 4.0，实测 6.42 —— 这就是总闸。
```

**每次录完先跑一遍这个**，比翻面板快得多。

### 单独验拇指跟随

```bash
g++ -std=c++20 -O2 -I src tools/hm20_diag/test_thumb_tracker.cpp -o trk
./trk recordings/xxx/capture.pcrec
```

它会把每一段遮挡的「入口 / 真值出口 / 保持误差 / 跟随误差」逐段列出来。
这就是我给你那两张表的出处 —— 你可以在自己的新录制上重跑，不用信我的数。

## 三、`meta.json` 里看当时的设置（不用写代码）

每次录制的目录里有一份缩进格式的 `meta.json`，直接用记事本打开。
`params` 段里是所有开关的**实际生效值**（不是控件值 —— 两者可能不一致）。

想确认"当时那个开关到底开没开"，5 秒就能自己查，不用跑脚本。

## 一句话的排查顺序

这几轮里最耗时间的三个 bug —— 手性没下发、`chainContinue` 默认关、`swing_` 只剩半截 ——
**全都是"代码看着在跑、计数器却是 0"**。

所以遇到"改了没反应"，**先看计数器是不是 0**：

```
链式续解×N      N=0  -> chainContinue 没开
(已跟 0.0°)          -> 跟随没生效
dorsumRepaired  一直没出现 -> 重捕没触发（或者确实没球掉）
ikActive 0%          -> IK 总闸关着，所有 IK 相关参数都白调
```
