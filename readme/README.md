## 二、做了什么

### 事件 20：任意控件被改动

`installUiEventRecorder()` 用 `findChildren` 自动给每个控件接线，记
控件名、类型、旧值→新值、墙钟。

**为什么自动接线而不是在 87 个控件上各写一句**：手写的真正代价不是打字，
是**漏**——新加控件时没人会记得补那一句，而漏掉的那个按墨菲定律就是出问题
的那个。自动接线的覆盖率天然是 100%，新控件自动纳入。这不是省事，是把
"完整性"从人的自觉变成机器的性质。

控件名优先级：`objectName()` → 按钮 `text()` → 同一行里前面最近的 QLabel →
`类型#序号`。最后那种回退**如实记进快照**而不是猜一个：一个叫
`QDoubleSpinBox#7` 的名字至少诚实，猜错的名字会把人引到错误的控件上。

### 事件 21/22 + 起录/停录全量控件快照

增量事件只记被改动过的。一个**全程没被碰过**的控件不产生任何事件，值在文件里
就是空白——而"没被碰过的那些"才是排查的背景板：出问题时要先确认其它东西都在
预期位置，才轮得到看变了的那几个。

停录那份让你不必重放整条增量流就知道最终配置——而重放本身是个会出错的步骤。

### pcrec.py

```bash
python pcrec.py 你的.pcrec --report      # 全场报告，一条命令讲完
python pcrec.py 你的.pcrec --timeline    # 只看时间轴
python pcrec.py 你的.pcrec --frozen      # 只看输出冻结
```

`--report` 的章节顺序是按**因果**排的，不是按块号：先看操作（人做了什么）→
动作（手做了什么）→ 标定（系统学到了什么）→ 输出（结果对不对）。倒过来看
必然会先怀疑输出。

新增函数：`timeline()` `ui_changes()` `ui_snapshot(start|stop)`
`fist_cycles()`。

`fist_cycles()` 从 curl 数握拳次数和起止帧——**curl 只用球心间距算**，
不经过腕部系、不经过四元数、不经过 anchor，关节角失效的那些帧里它还活着。
这正是它能当标定相位判据的原因，拿来数握拳同理。

## 三、装了 Qt6 真编译，抓到三个我自己的 bug

不是走查出来的，是跑出来的。这三个如果只靠看，一个都发现不了：

**1. `labelBefore` 一个标签都找不到。** 控件的 `parentWidget()->layout()` 是
外层 QVBoxLayout，而「标签 + 控件」那个 QHBoxLayout 是**嵌进去的子布局**，
控件根本不是外层布局的直接项。结果所有数值框都退化成 `QDoubleSpinBox#2` 这种
编号名。改成递归找真正持有它的那一层。

**2. `qt_spinbox_lineedit` 混进来。** QSpinBox 内部嵌着一个 QLineEdit，
是 `findChildren` 的合法结果，但不是用户能操作的控件。

**3. 最坏的一个：快照和事件的名字对不上。** 两处各自 `findChildren`、各自计数，
而第 2 条那些内部件参与了快照的计数、没参与事件的。于是同一个控件在快照里叫
`QSpinBox#4`、在事件里叫 `QSpinBox#3`——**基线和增量再也 join 不起来**，
而那是这两份数据唯一的用法。改成单一枚举口 `uiControls()`，过滤规则和序号
只允许有一份实现。

修完的实测：

```
20|直通模式 [check] 关 -> 开
20|限幅(rad/s) [dspin] 8 -> 3.5
20|最少支持数 [spin] 7 -> 9
20|详细度 [combo] 0 -> 1(Full)
20|ROM标定 [click] 点击
```

另外 pcrec.py 里也踩了两个，都是跑出来的：`marks` 是三元组不是 numpy 记录
（按二元组解包当场炸）；`param_deltas` 里存的已经是 dict，再 `json.loads`
一次会炸。

## 四、一个跟我无关但你该知道的问题

`PointCloudTestDialog_capture.cpp` 里有一处
`std::min(int64_t&, qint64&)` **在 gcc 上编译不过**——Linux 上 `qint64` 是
`long long` 而 `int64_t` 是 `long`，MSVC 上两者都是 `__int64` 所以你那边没事。

我确认过：**原始上传版本就有**（在原第 997 行），不是我引入的。
意思是这个项目目前在 Linux/gcc 上构建不了。要跨平台的话得加个显式转换。
