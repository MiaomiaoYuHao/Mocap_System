# 连线不跟手 · 输出链路延迟开关

## 一、先说结论：滤波多半不是主犯

你的直觉对了一半——链路里确实有滤波，而且默认就是开的（平滑档位默认「均衡」）。
但把四个来源按量级排一下，滤波排在最后：

| 来源 | 量级 | 原来能不能关 |
|---|---|---|
| **骨架调用限流** 写死 33ms(30Hz) | 平均 **+16ms**、最坏 +33ms | ❌ 硬编码 |
| **AI 线程被饿死** 写死 `LowestPriority` | 满载时可能 **+10~50ms**，且忽大忽小 | ❌ 硬编码 |
| 时序滤波 `Hm20PoseFilter`「均衡」 | 通常 **+3~8ms**（One-Euro 自适应，手动得快时几乎不引入滞后） | ✅ 平滑=关 |
| 关节角速度限幅 | **0**（只作用于 UDP，不影响面板连线） | ❌ 硬编码 |

**限流那一条是最可疑的**：点云自己可能跑 100fps 以上，骨架只有 30fps，
画面上就是「点已经动了、线还停在最多 33ms 前的位置」——这正是"连线追着点跑"的观感。
而且它对着 `latencyMs` 完全查不出来，那个数字只量 `process()` 内部，看起来一直很好看。

优先级那一条更阴险：**推理只要 3ms，排队却可能 40ms**，看诊断数字只会觉得"AI 很快啊"。

所以我没有只做一个滤波开关，而是把四项全做成开关，**再加一个实测读数**——
不靠感觉，靠毫秒数。

## 二、面板上多了什么

骨架那一行末尾新增：

```
[✓]低延迟直通   骨架刷新:[30Hz ▾]   [✓]速度限幅   滞后28ms = 推理3.2 + 排队8.4 + 陈旧17　骨架30Hz
```

### 「低延迟直通」——一键 A/B

勾上时同时做四件事：骨架刷新不限流、AI 线程优先级最低→普通、时序滤波关、
速度限幅关 + 点云输出端 One-Euro 关。

**勾上→晃手→取消→再晃手**，差别一眼可见。这就是你要的开关。

> 它**不改**那几个控件的勾选状态，只是把它们变灰临时旁路——退出直通时你原来的设置
> 原样回来，不会被覆盖。

### 「骨架刷新」——30 / 60 / 120Hz / 不限流

原来写死的那个 33ms。调高的代价是 AI 线程 CPU 占用成比例上涨，
**先看读数里的「推理」再决定**：
- 推理 3ms → 120Hz 也只占 36% 一个核，尽管调
- 推理 25ms → 连 60Hz 都跑不满，调了只是白排队（丢帧率会涨上去）

### 「速度限幅」

关节角每秒最多变 8rad。**只作用在 UDP 那一路，跟面板连线无关**。
所以"面板里连线不跟手"跟它无关，但"Unity 里手指跟不上"可能就是它。

关之前想清楚下游：它防的是标签串了/重捕那一帧甩出几十度的阶跃。软件模型无所谓，
真机械手收到超出自身能力的阶跃，要么饱和过冲、要么报保护停机——那是安全问题不是画质问题。

### 滞后读数

```
滞后28ms = 推理3.2 + 排队8.4 + 陈旧17　骨架30Hz
```

- **推理** = `process()` 本身耗时（含 ONNX）
- **排队** = 投递→worker 真正开跑 + 结果回传。**这一项大 = AI 线程抢不到 CPU，不是模型慢**
- **陈旧** = 限流造成的"这条线已经画了多久没更新"，取实测刷新间隔的一半

三项分开量才知道该调哪个：排队大就提优先级（勾直通，或后续做成独立选项），
推理大就降刷新率 / 确认是 Release 构建，陈旧大就把刷新调高。

## 三、建议的排查顺序

1. 勾「低延迟直通」，晃手。**如果跟手了** → 继续第 2 步定位是哪一项；
   **如果还是慢** → 瓶颈不在输出链路，在采集/检测/追踪那一段（看批处理窗口 12ms、
   相机曝光、USB 带宽）
2. 取消直通，只把「骨架刷新」调到 60Hz 或 120Hz，再晃手。多半到这一步就够了
3. 还想更快，把「平滑」调到「轻」——它的实测代价只有位置中位 1.48mm vs 均衡的 1.65mm，
   抖动 1.742 vs 1.500，差别很小，但滞后小一档
4. 「强」档不要在跟手场景用，实测滞后 3.4mm

**不建议动的**：`usePrevFrame`（上一帧位置喂给网络）。那是关联的先验，不是输出滤波，
关掉标签准确率会掉，跟延迟无关。

## 六、如果读数显示「排队」一直很大

那说明 AI 线程抢不到 CPU。除了勾直通（临时提到 NormalPriority），
还可以考虑把优先级单独做成一个下拉（最低/普通/高），我没做是因为
**普通优先级下如果 AI 线程真的吃满一个核，会开始跟采集线程抢**——
你的相机是 4 路，这个风险要在真机上量过再决定，不该我在这里替你拍板。

先用直通量出「排队」到底占多少，再决定值不值得常开。
