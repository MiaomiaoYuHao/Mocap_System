## 五个靠真机数据才发现的问题

1. **anchor 坐标系错配** —— 近节骨轴与真实方向差 111°~157°，5个分段全错，仿真上完全测不出
2. **关联阈值 0.55 偏严** —— 改 0.35 后屈伸段腕部有效率 46%→60%，简单场景逐位不变
3. **手背模板可能标签反向** —— 五重对称，用绕序规范化根治（模板误差 11.96mm→0.11mm）
4. **手性写死右手** —— 标定向导根本没这个选项；已做成面板开关（但实测翻转会更差，保持右手）
5. **骨架时间戳记错** —— 记的是结果返回时的墙钟，晚 30ms，导致离线对齐匹配率只有 16.8%

## 上手顺序

1. 编译，修掉可能剩下的 Qt 层小错
2. 打开点云面板，确认「右手」勾选状态（默认沿用原行为）
3. 点「ROM标定」→ 五指张开到底↔握拳到底来回两三遍 → 再点结束（弹窗报覆盖度）
4. Unity 端：把 `tools/unity/MocapHandReceiver.cs` 拖进工程，骨骼拖进 Inspector。
   **先用 Quaternion 模式确认链路通**（假设最少、最直观），再切 JointAngles 调旋转轴
5. 观察跟手感：手摊开时应该很稳（4.9/5指有效），自由动作约 3.4/5 指
