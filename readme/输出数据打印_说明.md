## 二、怎么用

1. 编译，打开点云测试面板
2. 勾选「叠加显示骨架」（没这个就没有输出）
3. 勾选「**打印输出数据**」→ 右侧出现面板，可拖分隔条调宽
4. 左上角下拉切三种视图

| 视图 | 看什么 |
|---|---|
| **关节角(M3DS)** | 16 维关节角。左列是解算原始角、右列是实际发出去的角、中间行程条 + `新算/保持/触限` 标记 |
| **分段四元数(M3DQ)** | 16 段的相对父节点四元数（Unity 直接喂 `bone.localRotation` 的那份）+ 世界系 + 每段来源颜色标注 |
| **原始报文** | UDP 上真跑的字节，M3DS 124B / M3DQ 556B，可直接跟 Unity 端或 Wireshark 逐字节对 |

按钮：**冻结**（停画面不停数据）、**复制**（当前帧全部内容含完整 hex 进剪贴板）、**记CSV**（逐帧写文档目录，列含原始角/输出角/腕部位姿/flags/segSource）。

窗口宽度、分隔条位置、勾选状态都进 QSettings，下次自动恢复。

## 三、三条设计决定，改之前先读

### ① 数据源是「实际发出去的那两个信号」，不是重算

`PointCloudTestDialog::handPoseForUdp` / `segmentQuatsForUdp` 这两个信号，
MainWindow 一头接 `UdpSender`、面板一头接监视器——**同一次 emit 的两个消费者**。

不要改成从 `onSkeletonResultReady` 的 `result` 重新算。那样会跳过
**时序滤波 → ROM 映射 → 速度限幅**这三步，而链路上最容易骗人、最需要被看见的
恰恰是这三步。重算出来的数字很好看，但它不是发出去的那份。

### ② UI 刷新不由数据率驱动

120fps × 48 个数字，每帧 setText 会把 GUI 线程吃满——跟你在
`skeletonDiagLabel_` 上踩过的 `setWordWrap(true)` 布局震荡是同一类问题，只是更狠。

做法：**槽函数只往快照结构塞值**（纯赋值，零 UI 调用），另有 10Hz 定时器负责重绘。
上游 120Hz 还是 1000Hz，UI 开销恒定。

### ③ 数字区自绘

不用 QLabel 矩阵/QTableWidget，一次 `paintEvent` 画完，零控件、零布局协商。
同 `PointCloudWidget` 的路子。

**不勾选时 `setActive(false)`：槽函数第一行 return、定时器停转，对原链路零开销。**

## 四、顺带做的一件必要的事

M3DS/M3DQ 的打包从 `UdpSender.cpp` 抽到了 `src/net/HandPacket.hpp`，发送端和
监视器共用同一个函数。

理由：否则就有两份布局定义，哪天改了包格式忘了同步另一份，**监视器显示的字节和
真正发出去的字节不一致——而这种不一致只会在你正拿它排查问题的时候骗你**，
是最坏的一类 bug。

`tests/test_hand_packet.cpp` 拿重构前那份手写代码当参照物逐字节比对，
以后谁再动布局立刻红。

## 五、`jointAnglesDebug` 这根线为什么值得加

UDP 里那 16 个数是 ROM 映射 + 速度限幅**之后**的结果。光看它分不清两种完全
不同的故障：

| 现象 | 原始角 | 输出角 | 病因 | 解法 |
|---|---|---|---|---|
| 机械手不动 | 不动 | 不动 | 解算没解出来（遮挡/标定坏） | 查遮挡、查自标定 |
| 机械手不动 | 在动 | 不动/贴限位 | ROM 压平了 / 限幅削掉了 | 重做 ROM 标定 |

这两种解法正好相反，所以必须能同屏对照。面板里左列「解算°」右列「输出°」，
行程条贴到两端会标 **触限** —— 你 ROM 标定按钮的 tooltip 里写的
「不做时关节触限率 100%」，现在能一眼看见了。

`jointAnglesDebug` 只给 UI，不进 UDP，包格式一个字节没变。

## 七、下一步能顺手做的

- **和 Unity 端对账**：面板「原始报文」的 hex 跟 `tools/unity/udp_monitor.py` 收到的
  逐字节比。不一致 = 网络层问题；一致但 Unity 里手型不对 = 坐标系换算问题。
  这条能把"到底哪一段出错"从猜变成测。
- **CSV 画曲线**：录一段 `handout_*.csv`，画 `raw_deg_i` vs `out_deg_i`。
  两条线平行 = ROM 正常；输出被削平成直线 = ROM 该重标。
- 面板现在只读不写。要加"手动注入一帧固定关节角发给 Unity"（验证 Unity 端绑定
  是否正确、绕开整条解算链路），在 `HandOutputMonitor` 里加个按钮直接
  `emit` 一次即可，`wire::buildM3DS` 已经现成。
